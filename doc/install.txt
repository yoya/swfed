% cd src
% phpize
% ./configure
% make
% su

* requirements

- PHP 7.2 or newer
- zlib (required)
- libpng, giflib (optional; without them PNG / GIF support is disabled)
- liblzma (xz) (optional; without it LZMA compressed SWF (ZWS) can't be read)

configure first uses a library as it is when the compiler finds it without
any option (system directories, the macOS SDK). Otherwise it looks for the
library with pkg-config, then under /usr/local, /usr, /opt/homebrew and
/opt/local, and uses the first one found.
Use --with-zlib-dir=DIR / --with-png-dir=DIR / --with-gif-dir=DIR /
--with-lzma-dir=DIR to give the install prefix explicitly, and
--without-png-dir / --without-gif-dir / --without-lzma-dir to build without
PNG / GIF / LZMA support.

* macOS (Homebrew)

% brew install zlib libpng giflib xz pkg-config
% phpize
% ./configure

If configure still can't find them (e.g. without pkg-config), give the
prefixes explicitly. On Apple Silicon Homebrew lives in /opt/homebrew,
on Intel Macs in /usr/local:

% ./configure --with-zlib-dir=/opt/homebrew/opt/zlib \
              --with-png-dir=/opt/homebrew/opt/libpng \
              --with-gif-dir=/opt/homebrew/opt/giflib \
              --with-lzma-dir=/opt/homebrew/opt/xz
